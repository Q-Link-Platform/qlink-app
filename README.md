## 🌟 Core Features
- **⚡ Dynamic Recency Contact Ranking**: Conversations re-order in real time based on message recency and unread status.
- **✓✓ Triple-State Delivery Ticks**: Single Grey (Sent), Double Grey (Delivered), Double Glowing Green (Seen).
- **🌊 Real-Time Typing Waves & Presence**: Animated typing wave visualizers and active green presence dots.
- **⏳ 24-Hour Ephemeral Media**: Shared photos and media attachments automatically clean up after 24 hours.
- **🚨 Q-BEACON Emergency Alert Protocol**: High-priority siren chimes and full-screen elevation for urgent situations.
- **🎙️ Inline Voice Memos**: One-tap recording with interactive scrubbable audio waveforms.
- **🌐 Community Social Feed**: Community updates with mentions (`@`), hashtags (`#`), and emoji reactions.
- **👥 Global User Directory**: Search peers by handle and interests with Aura engagement rankings.
- **💎 VIP Profile Showcase**: Diamond 10 & Sapphire 10 interactive cards with looping canvas art.
- **🖥️ Standalone Windows App (.exe)**: System Tray background mode with native toast notifications.
- **⚡ Hardware GPU Control**: Toggle between 60fps Ultra High Performance and Battery Saver mode.
